AI Forex Trading System

An end-to-end AI-powered Forex Trading System that combines Machine Learning, Reinforcement Learning, Technical Analysis, and Business Intelligence to analyze financial markets, generate trading signals, predict price movements, and visualize trading performance through an interactive Power BI dashboard.

---

Project Overview

This project demonstrates a complete AI-based forex trading workflow, from raw market data to intelligent trade recommendations. It integrates data preprocessing, feature engineering, predictive modeling, reinforcement learning, technical indicators, model evaluation, and interactive dashboards for comprehensive trading analytics.
